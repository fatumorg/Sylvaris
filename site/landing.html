Two ways in

With Nix, every setting is a typed Home Manager option and the tools each part needs come along with it. Everywhere else, install the packages for your distribution and run make install. Every route here was installed and started in a clean container before it went on this page.

Then add sylvaris to your compositor's autostart and open the settings with sylvaris settings.

How heavy is it?

Measured in the headless test harness with demo data on one 2560×1440 screen. Memory is the whole Sylvaris process, including SylStack, Qt and, with a GPU, the driver's mappings. CPU is a share of one core over 20 idle seconds.

SituationSoftware renderingGPU (NVIDIA)
Idle, every part on150 MB · 0.5 % CPU270 MB · 0.5 % CPU
After opening every panel once, 25 s later168 MB348 MB
Idle, only the bar and notifications101 MB · 0.4 % CPU243 MB · 1.6 % CPU

Panels are built when you open them; their windows are freed the moment they close and the rest 20 seconds later. tests/bench/bench.sh measures your own machine the same way.

Make your own pieces

A plugin is a folder with a small JSON file and some QML. It can be a bar widget, a panel or a background helper, and it gets the same theme, glass and commands the built-in parts use.

sylvaris plugins new weather-plus bar writes a working starter to edit.
