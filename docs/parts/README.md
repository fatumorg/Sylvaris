# Parts

Sylvaris is made of parts. Each one can be turned off, and a part that is off is never loaded, along with anything only it uses (see [turning parts off](../configuration.md#turning-parts-off)).

## Every day

- [SylBar](bar.md), the bar, on any edge
- [SylCenter](center.md), the control center with Wi-Fi and Bluetooth orbits
- [SylClock](clock.md), a live sky, the weather and a calendar
- [SylNotify](notify.md), notifications and Do Not Disturb
- [SylIsland](island.md), what is going on right now, with controls (off by default)
- [SylDeck](deck.md), a dock (off by default)
- [SylPad](pad.md), the app launcher

## Tools

- [SylSwitch](switcher.md), Alt+Tab
- [SylClip](clip.md), clipboard history
- [SylCapture](capture.md), screenshots, recordings and an image editor
- [SylViewer](viewer.md), images and videos
- [SylFiles](files.md), a file manager with tabs, previews and undo
- [SylMedia](media.md), the player, an equalizer and device batteries
- [SylPower](power.md), the power menu
- [SylPaper](paper.md), wallpapers

## System

- [SylSettings](settings.md), every setting in one place
- [SylTheme](theme.md), themes with a live preview
- [SylSync](sync.md), your theme's colours in other apps
- [SylAccessibility](access.md), zoom, colour filters, text and pointer size
- [SylLock](lock.md), [SylGreet](greet.md) and [SylPolkit](polkit.md), experimental

## Plugins

[SylPlugins](../plugins/README.md) runs your own widgets and the built-in plugins: [Diver](../plugins/diver.md), [AirPods](../plugins/airpods.md) and [FaTest](../plugins/fatest.md).
